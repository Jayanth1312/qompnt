Installation

Grab the qomp CLI for your platform with , , — click to copy

Or download a binary from GitHub and put qomp on your PATH.

In any project:

qomp init

Files land under components/qompnt/ with a qomp.json config. 

qomp add accordion
qomp update
qomp upgrade

CDN

Skip the CLI: copy markup from the site and link the stylesheets. 

<link rel="stylesheet" href="https://qompnt.vercel.app/static/tokens.css">
<link rel="stylesheet" href="https://qompnt.vercel.app/static/qompnt.css">
<!-- optional theme, e.g. apple -->
<link rel="stylesheet" href="https://qompnt.vercel.app/static/themes/apple.css">

CLI

qomp init walks you through a design system and which components to install. Non-interactive: 

qomp init --theme apple --components minimal
# --components: all | minimal | none | button,card,...

Themes

Light and dark ride on the data-theme attribute on the html element. Each design system is one stylesheet of tokens over the same contract — Claude (default), Apple, Linear, Notion, and the rest.

After qomp init, link from components/qompnt/styles/:

<link rel="stylesheet" href="/components/qompnt/styles/tokens.css">
<link rel="stylesheet" href="/components/qompnt/styles/qompnt.css">
<link rel="stylesheet" href="/components/qompnt/styles/themes/apple.css">

shadcn

Needs components.json and tsconfig.json in your project. Files land in components/qompnt/, same layout as qomp init:

— click to copy. 

npx shadcn@latest add https://qompnt.vercel.app/r/<slug>.json

After adding a registry item, import tokens.css and qompnt.css from components/qompnt/styles/, then use the installed HTML as JSX (or import snippets from those files). 

import "@/components/qompnt/styles/tokens.css";
import "@/components/qompnt/styles/qompnt.css";

Plain HTML

Link the stylesheets (CDN or local after init), paste the component markup into your page. No build step required. 

<!doctype html>
<html lang="en" data-theme="light">
<head>
  <link rel="stylesheet" href="https://qompnt.vercel.app/static/tokens.css">
  <link rel="stylesheet" href="https://qompnt.vercel.app/static/qompnt.css">
</head>
<body>
  <!-- paste button / accordion / … markup here -->
</body>
</html>

React or Next.js or Vite

Import the CSS once in your entry file — main.tsx for React or Vite, app/layout.tsx (App Router) or _app for Next.js — then paste markup as JSX. Keep class names and attributes; self-close void tags. Static HTML works in Next.js Server Components; use a client component only where you need interactivity. 

import "./components/qompnt/styles/tokens.css";
import "./components/qompnt/styles/qompnt.css";
// import "./components/qompnt/styles/themes/apple.css";
export function Example() {
  return (
    <button type="button" className="btn">Save</button>
  );
}

Svelte

Import CSS in +layout.svelte or main.js, paste markup into a .svelte file. 

<script>
  import "../components/qompnt/styles/tokens.css";
  import "../components/qompnt/styles/qompnt.css";
</script>

<button type="button" class="btn">Save</button>

Astro

Import CSS in the layout frontmatter or global stylesheet. Paste HTML into .astro templates as-is. 

---
import "../components/qompnt/styles/tokens.css";
import "../components/qompnt/styles/qompnt.css";
---
<button type="button" class="btn">Save</button>

Angular

Add the stylesheets to angular.json styles, or import them in styles.css. Paste markup into the component template. 

// angular.json → projects.*.architect.build.options.styles
"src/components/qompnt/styles/tokens.css",
"src/components/qompnt/styles/qompnt.css"
<button type="button" class="btn">Save</button>

Vue

Import CSS in main.js, paste markup into an SFC template (use class, not className). 

import "./components/qompnt/styles/tokens.css";
import "./components/qompnt/styles/qompnt.css";
<template>
  <button type="button" class="btn">Save</button>
</template>
