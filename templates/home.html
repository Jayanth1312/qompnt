FAQ

What is Qompnt?

A small library of HTML components styled with a token contract. Install with the qomp CLI, copy-paste markup, or pull from the shadcn registry. The site itself is the living catalog.

How do I install the CLI?

Download qomp from GitHub Releases, or copy an install command from the home page (scoop / brew / Windows script). Each one pulls the binary from the latest GitHub release. Then in any project run qomp init. It pulls themes and components from this site into components/qompnt/.

How do I use a component?

Prefer qomp add <slug> after init. Or open any component page, copy the HTML, and link tokens.css plus qompnt.css. Or run npx shadcn@latest add https://qompnt.vercel.app/r/<slug>.json.

Do components have animations?

Some do — accordion, dialog, toast, and others — and those pages expose an Animation switch so you can turn motion off. The site also respects prefers-reduced-motion.

How do design systems and themes work?

Light and dark ride on data-theme. Each design system is one stylesheet of tokens over the same contract — switch Claude, Notion, Linear, and the rest from the Components gallery without changing markup.
